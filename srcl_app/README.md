# srcl_app

Sistema de Reserva de Citas en Línea (SRCL) - Módulo Móvil en Flutter.

## Evidencia SENA
- **Código:** GA7-220501096-AA3-EV01
- **Aprendiz:** Andres Felipe Cárdenas Álvarez
- **Tecnología:** Flutter / Dart

## Vistas de la Aplicación
1. **WelcomeScreen:** Pantalla de bienvenida con logo, diseño en gradiente y acceso.
2. **HomeScreen:** Menú principal con Drawer lateral, tarjetas navegables y BottomSheet modal informativo.
3. **BookingScreen (Funcionalidad 1):** Agendamiento de citas con selección de servicios, DatePicker y horario.
4. **AppointmentsScreen (Funcionalidad 2):** Historial y consulta de citas guardadas con ListView y cancelación.
